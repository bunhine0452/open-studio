01 / Concepts

열 가지 컨셉,
하나의 모션 엔진

주제에 맞춰 화면·장면 전환·효과음이 통째로 바뀌어요. 모든 효과음과 배경음악은 코드로 합성해서 저작권 걱정이 없어요. 눌러서 크게 보세요.

02 / How it works

말 한마디가
결과물이 되기까지

Claude Code 가 순서대로 진행하고, 공개처럼 되돌리기 어려운 일 앞에서는 반드시 멈춰서 물어봐요.

  1. 조사와 출처웹에서 최신 자료를 찾고, 숫자와 날짜는 공식 문서로 확인해요. 출처는 화면·설명란에 남아요.
  2. 대본·카피해요체로 짧게. 번역투·상투구·줄표 같은 AI 말투를 점검해요.
  3. 읽는 소리로 바꾸기3D → 쓰리디, SSH → 에스에스에이치, 3개 → 세 개. 자막은 원래 표기로 되돌려요.
  4. 무료 목소리와 낱말 시각edge-tts 로 목소리를 만들고 낱말마다 시각을 받아 자막을 맞춰요.
  5. 웹 모션 렌더HTML/CSS 로 장면을 짜고 헤드리스 Chrome 이 프레임마다 시각을 맞춰 찍어요. 같은 시각이면 언제나 같은 화면.
  6. 점검 후 확인규격·음량·과장 광고·표절을 점검하고, 올리기 전에 사람에게 물어봐요.

09 / FAQ

자주 묻는 질문

정말 무료인가요?

스킬, 기본 목소리(edge-tts), 효과음, 배경음악, 렌더는 무료예요. Claude Code 를 쓰려면 Claude 유료 요금제나 API 결제가 필요해요. 더 자연스러운 목소리를 원하면 ElevenLabs(유료) 키를 넣을 수도 있어요.

윈도우에서도 되나요?

맥(애플 실리콘)에서 만들고 새로 받은 사본으로 다섯 도구를 모두 확인했어요. 리눅스·윈도우는 같은 파이썬·ffmpeg·Chrome 이라 될 것으로 보지만 아직 직접 확인하지 못했어요. 돌려 보고 이슈로 알려 주세요.

결과물을 상업적으로 써도 되나요?

코드는 MIT, 글꼴 Pretendard·Hahmlet 은 OFL 이라 상업적으로 써도 돼요. 효과음과 배경음악은 코드로 합성해서 별도 저작권이 없어요. 넣는 사진과 정보의 권리는 쓰는 사람이 확인해야 해요.

AI 로 만든 영상은 유튜브에서 제재받지 않나요?

유튜브는 AI 사용 자체가 아니라 반복적인 저품질 대량 생산을 단속해요. 그래서 이 도구는 주제마다 사실을 확인하고, 공개는 사람이 누르게 해 뒀어요. AI 음성은 설명란에 밝히세요.

새 컨셉을 만들 수 있나요?

네. 색·글꼴·효과음 묶음은 spec 한 곳에서 바꾸고, 새 컨셉은 CSS 한 블록(전환·배경·자막 모양)과 효과음 표 한 줄을 더하면 돼요. 방법은 저장소의 themes.md 에 있어요.
