# 상세페이지 만들기

이 SKILL.md 가 있는 폴더를 `$DP` 라고 부른다. 렌더 `uv run $DP/scripts/detail.py <폴더>`, 누끼 `uv run $DP/scripts/cutout.py <사진> <결과.png>`(detail.py 가 알아서 부른다).
글꼴은 같은 플러그인의 `$DP/../shorts/fonts`. 처음이면 `uv run $DP/../shorts/scripts/doctor.py`.

먼저 읽는다: `references/sections.md`(섹션 종류·detail.json·문구 규칙).

## 사용자에게 받는 것 (한 번에 묻는다)

- 상품명, 브랜드, 카테고리, 판매처(스마트스토어·쿠팡·토스, 기본 셋 다)
- 상품 사진(여러 장, 폴더째로 받아도 된다). 흰 배경 정면 사진이 한 장 있으면 누끼로 히어로·대표 이미지를 만든다
- 특징·사양(크기·무게·재질·구성), 옵션, 사용법, 주의사항, 배송·교환 정책
- 실제 받은 후기(있으면). **없으면 후기 섹션을 넣지 않는다. 후기를 지어내지 않는다.**
- 브랜드 색(없으면 상품 사진에서 대표 색을 골라 제안), 원하는 분위기
경쟁 상품 링크를 주면 읽어서 소구점을 비교하되, 그 글이나 사진을 베끼지 않는다.

## 흐름

1. **폴더**: 현재 작업 폴더의 `detailpage/<영어-slug>/`, 사진은 `photos/`.
2. **설득 흐름 짜기**: 히어로(한 줄 약속) → 공감(고객이 겪는 불편 2~4개) → 해결(이 상품 한 줄) → 포인트 2~4개(장마다 사진 한 장 + 근거 숫자) → 장면(쓰는 모습) → 비교 → 사양 → 사용법 → 후기(실제만) → 자주 묻는 질문(살 때 망설이는 이유에 답) → 배송·교환 → 마무리. 짧은 구성 10~13섹션, 긴 구성 15~20섹션.
3. **카피**: 해요체. 제목 두 줄 안, 강조어 `[대괄호]`. 숫자에는 조건을 붙인다("실온 20℃, 가득 채운 상태 기준"). 사용자가 주지 않은 수치·인증·수상은 쓰지 않는다.
4. **스타일**: `clean`(흰 바탕 기본) · `warm`(식품·리빙, 크림색) · `bold`(행사·젊은 층, 브랜드 색 면) · `dark`(전자·남성용품) · `soft`(뷰티·유아). 브랜드 색 하나만 받으면 나머지 색(옅은 바탕·글자용 진한 색·마무리 면)은 대비를 맞춰 자동으로 만든다.
5. **문구 점검**: `detail.py <폴더> --check`. 걸린 표현은 근거가 없으면 고친다(최상급·1위, 100%·완벽, 의약품 오인, 부작용 없음, 추천·인증, 다이어트, 기능성). 식품·건강기능식품·화장품·의료기기는 업종 규정이 더 엄격하다고 사용자에게 알린다.
6. **미리보기**: `detail.py <폴더> --preview` → `out/preview.jpg` 를 직접 본다(글 넘침·사진 잘림·빈 칸·색 대비).
7. **내보내기**: `detail.py <폴더>` → `out/860|780|1080/full.jpg`(한 장), `01.jpg…`(섹션 경계에서 나눈 조각, 같은 이름 webp), `thumb-white.jpg`(흰 배경 대표 이미지), `thumb-styled.jpg`, `page.html`(편집용 원본).
8. **보고**: 섹션 수, 스타일과 이유, 결과 경로, 문구 점검 결과, 사용자가 확인해야 할 것(수치·정책).

## 자주 틀리는 것

- 사진이 부족하면 같은 사진을 여러 번 쓰지 말고 섹션을 줄이거나 글·표로 채운다.
- 누끼는 배경과 상품 색이 비슷하면 가장자리가 먹힌다. 결과 PNG 를 열어 보고, 이상하면 `cutout.py --model u2net` 으로 다시.
- 스마트스토어는 조각 이미지를 위에서부터 순서대로 올린다. 쿠팡은 780 폭을 쓴다.
- 브랜드 색이 아주 밝으면(노랑 등) 제목 강조는 자동으로 진하게 바뀐다. 의도와 다르면 `brand_color` 를 조금 진하게.
