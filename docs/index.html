01

쇼츠

“쇼츠 만들어 줘: 비밀번호 유출 확인하는 법”
  • 자료 조사와 공식 출처 확인 → 40~50초 대본
  • 3D는 쓰리디, SSH는 에스에스에이치로 읽고 자막은 원래 표기로
  • 무료 목소리(edge-tts) + 낱말마다 켜지는 자막
  • 주제에 맞는 테마 5종: 글리치·픽셀·페이지 넘김 전환과 그에 맞는 효과음
쇼츠 자동화 스킬 99,000원~여기선 0원
02

카드뉴스

“이 링크를 카드뉴스로 만들어 줘”
  • 8~10장, 한 장에 메시지 하나: 표지 → 문제 → 핵심 → 정리 → 할 일
  • 장 종류 11가지, 한국어 낱말 단위 줄바꿈, 넘치면 자동으로 맞춤
  • PNG 세 크기 + PDF + 릴스 영상 + 캡션·해시태그·대체 텍스트
  • 브랜드 키트(이름·핸들·로고·색)를 한 번 저장해 계속 사용
AI 카드뉴스 도구 구독 · 제작 대행여기선 0원
03

상세페이지

“상세페이지 만들어 줘. 사진은 이 폴더에 있어”
  • 히어로 → 공감 → 해결 → 포인트 → 비교 → 사양 → 질문 → 마무리
  • 브랜드 색 하나로 전체 색 자동, 스타일 5가지, 누끼(배경 제거)
  • 스마트스토어 860 · 쿠팡 780 · 토스 1080 + 조각 + 대표 이미지 + HTML 원본
  • 과장 광고 점검: 최상급·100%·의약품 오인·출처 없는 후기
크몽 60,000원~SaaS 월 29,000~149,000원여기선 0원
04

쇼핑 쇼츠

“이 상품으로 15초 쇼핑 쇼츠 만들어 줘”
  • 누끼 상품이 무대 위로, 장점 칩, 정가 → 할인가 가격표
  • 코드로 합성한 배경음악(저작권 없음), 말하는 동안 자동으로 작아져요
  • 자막본·무자막본, 제휴면 '광고' 표시와 대가성 문구
쇼츠 자동 프로그램 350,000원/년SaaS 월 29,900~249,000원여기선 0원
05

블로그 글

“‘git reflog’ 키워드로 블로그 글 써 줘”
  • 검색 의도 파악 → 자료·출처 → 제목 3안·요약·소제목·표·질문
  • 표절 점검: 출처 원문과 28자 이상 같은 곳을 찾아요
  • 네이버·티스토리 편집기에 붙여 넣어도 서식이 남는 HTML, 워드프레스 초안

FAQ

자주 묻는 질문

정말 무료인가요?

스킬, 기본 목소리(edge-tts), 효과음, 배경음악, 렌더는 무료예요. Claude Code 를 쓰려면 Claude 유료 요금제나 API 결제가 필요해요. 더 자연스러운 목소리를 원하면 ElevenLabs(유료) 키를 넣을 수도 있어요.

윈도우에서도 되나요?

맥(애플 실리콘)에서 만들고 확인했어요. 리눅스·윈도우는 같은 파이썬·ffmpeg·Chrome 이라 될 것으로 보지만 아직 직접 확인하지 못했어요. 돌려 보고 이슈로 알려 주세요.

만든 결과물은 상업적으로 써도 되나요?

코드는 MIT, 글꼴 Pretendard 는 OFL 이라 상업적으로 써도 돼요. 효과음과 배경음악은 코드로 합성해서 별도 저작권이 없어요. 넣는 사진과 정보의 권리는 쓰는 사람이 확인해야 해요.

AI 로 만든 영상은 유튜브에서 제재받지 않나요?

유튜브는 AI 사용 자체가 아니라 반복적인 저품질 대량 생산을 단속해요. 그래서 이 도구는 주제마다 사실을 확인하고, 공개는 사람이 누르게 해 뒀어요. AI 음성은 설명란에 밝히세요.
