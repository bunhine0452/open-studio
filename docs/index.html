자주 묻는 질문

    
정말 무료인가요?
스킬, 기본 목소리(Supertonic 3, 내 컴퓨터에서 실행), 효과음, 배경음악, 렌더는 무료예요. Claude Code 를 쓰려면 Claude 유료 요금제나 API 결제가 필요해요. 원하면 ElevenLabs(유료) 목소리로 바꿀 수 있어요.

    
윈도우에서도 되나요?
맥(애플 실리콘)에서 만들고, 새로 받은 사본으로 다섯 도구를 모두 확인했어요. 리눅스·윈도우는 같은 파이썬·ffmpeg·Chrome 이라 될 것으로 보지만 아직 직접 확인하지 못했어요.

    
결과물을 상업적으로 써도 되나요?
코드는 MIT, 글꼴은 OFL, 목소리 모델은 상업 이용이 허용된 OpenRAIL-M 이에요. 효과음과 음악은 코드로 합성해서 별도 저작권이 없어요. 넣는 사진과 정보의 권리는 쓰는 사람이 확인해야 해요.

    
새 컨셉을 만들 수 있나요?
CSS 한 블록(전환·배경·자막 모양)과 효과음 표 한 줄을 더하면 돼요. 방법은 저장소의 themes.md 에 있어요.
