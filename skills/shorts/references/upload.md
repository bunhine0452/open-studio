# YouTube Studio 업로드 (선택, Chrome 확장 Claude in Chrome 이 있을 때)

업로드·공개는 되돌리기 어려운 공개 행동이다. 영상·제목·설명·공개 시각을 사용자에게 먼저 확인받는다. 영상 삭제는 하지 않는다.

1. `https://studio.youtube.com/` 을 새 탭에 연다 → 왼쪽 위 채널 이름이 사용자가 말한 채널인지 확인. 다르면 멈추고 사용자가 바꾼다.
2. 만들기 → 동영상 업로드 → 파일 입력에 mp4 를 **한 번만** 올린다(여러 번 누르면 초안이 겹친다). 확장의 파일 업로드 한도가 10MB 안팎이면 먼저 줄인다:
   `ffmpeg -i in.mp4 -c:v libx264 -crf 21 -preset slow -c:a copy -movflags +faststart in-upload.mp4`
3. 세부정보: 제목(spec `title`), 설명(caption.txt 그대로, `<` `>` 금지), '아동용 아님', 필요하면 카테고리·언어.
   AI 사용 공개: 실사 인물을 만들었거나 실제 사건 영상을 바꿨으면 '예'. AI 음성만 썼으면 설명란 표기로 충분하다.
4. 다음 ×3 → 공개 방식: 사용자가 말한 대로(비공개·일부 공개·공개·예약). 예약 시간은 드롭다운에서 고르고, 고른 값을 확대해 확인한다.
5. 저장/예약 후 콘텐츠 목록에서 실제 상태(공개 방식·예약 시각)를 다시 확인하고 영상 주소를 보고한다.

- 쇼츠 설명란·댓글 링크는 눌리지 않는다. 눌리는 곳은 채널 프로필 링크뿐이라, 끝 카드에 짧은 주소를 보여 준다.
- 고정 댓글은 영상이 공개된 뒤, 채널 인증이 된 뒤에만 고정할 수 있다.
- 인증 전 채널은 하루 업로드 수 한도가 있다.
