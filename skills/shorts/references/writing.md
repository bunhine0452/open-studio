# 대본 · 읽기 · 문체

## 대본
- 해요체. 한 문장 한 생각. 문장 길이에 변화를 준다. 공백 빼고 230~300자면 40~50초.
- 첫 문장 = 훅: 돈·시간·위험·궁금증 중 하나를 바로 꺼낸다. 인사·채널 소개·"오늘은 ~를 알아볼게요" 금지.
- 끝 문장 = 오늘 해 볼 한 가지. 연재 예고·"구독 좋아요" 는 넣지 않는다.
- 상식형·몇 년 된 밈은 버린다. 이번 주 소식이나 직접 해 본 결과처럼 새 정보를 담는다.
- 같은 대상은 끝까지 같은 이름으로 부른다(한 번 '저장소'면 끝까지 '저장소').

## 읽는 소리 (쇼츠의 질은 여기서 갈린다)
음성 엔진은 영어·숫자·약어를 엔진마다, 문맥마다 다르게 읽는다. "3D"를 "삼디"로 읽는 순간 영상이 싸 보인다.
그래서 **대본(narration.txt)에는 개발자가 실제로 소리 내는 한글**을 쓰고, **자막은 원래 표기**로 되돌린다.
`speakable.py` 가 사전(READ)과 숫자 규칙으로 바꾸고 caption_map 을 만든다. 사전에 없는 건 '확인 필요'로 알려 준다.

| 쓴 글 | 읽는 소리 | 틀린 예 |
|---|---|---|
| 3D · 2FA · 5G · 4K · M4 | 쓰리디 · 투에프에이 · 파이브지 · 포케이 · 엠포 | 삼디 · 이에프에이 |
| SSH · PXE · GUI · SQL | 에스에스에이치 · 픽시 · 지유아이 · 에스큐엘 | 쉬 · 피엑스이 |
| JSON · YAML · nginx · sudo | 제이슨 · 야믈 · 엔진엑스 · 수도 | 제이에스오엔 |
| API · GPT · SDK · CLI | 에이피아이 · 지피티 · 에스디케이 · 씨엘아이 | (영어 그대로 두면 엔진마다 다름) |
| 2.1.312 · v2.1 · .env | 이 점 일 점 삼백십이 · 버전 이 점 일 · 닷 엔브 | 이점일삼일이 |
| 3개 · 20명 · 11시간 · 2배 | 세 개 · 스무 명 · 열한 시간 · 두 배 (세는 말은 고유어) | 삼 개 · 이십 명 |
| 30일 · 1분 · 2026년 · 50% · $100 | 삼십 일 · 일 분 · 이천이십육 년 · 오십 퍼센트 · 백 달러 (한자어) | 서른 일 |
| 6월 · 10월 | 유월 · 시월 | 육월 · 십월 |
| 1:16 · 1대 16 | 일 대 십육 | 한 대 십육 |
| 깃허브 별 6,600개 | 깃허브 스타 육천육백 개 (화면엔 ★) | 별 |

- 확신이 없으면 그 제품의 공식 발표 영상이나 국내 개발 유튜브에서 어떻게 부르는지 찾아보고, 그래도 애매하면 화면 글자에만 쓰고 대본에서는 풀어 말한다.
- 자주 쓰는 낱말이 사전에 없으면 `scripts/speakable.py` 의 `READ` 에 더한다(그 자체가 이 도구를 좋게 만드는 기여).
- '3번'처럼 횟수(세 번)·번호(삼 번)가 갈리는 건 문맥으로 정한다.
- 자막 표기: spec `caption_map` `{"에스에스에이치": "SSH", "깃 리셋 하드": "git reset --hard"}` — 키는 narration 낱말 그대로, 마지막 낱말은 앞부분 일치라 조사("에스에스에이치로")는 남는다.

## 문체 점검 (음성 만들기 전에 매번)
`speakable.py` 가 1차로 잡는다. 그다음 소리 내 읽어 걸리는 곳을 고친다.
- 번역투·피동·명사화: "~를 통해", "~에 의해", "~에 있어", "~하는 것이 가능" → 주어를 세우고 능동으로.
- 상투구·과장: "중요한 점은", "결론적으로", "혁신적인", 마무리 감탄.
- 기계적 꾸밈: 습관적 3단 나열, "X가 아니라 Y", 줄표(—) 이어 붙이기, 곡선 따옴표.
- 꾸밈 부사(실제로·사실상·정말·제대로·깔끔하게), 얼버무림("~수 있습니다" 반복), '핵심은·결국·정리하면'.
