# 처음 쓰는 분을 위한 안내서

코딩을 몰라도 됩니다. 아래 순서대로 복사해서 붙여 넣으면 첫 쇼츠까지 30분 안팎이면 됩니다.
명령은 회색 상자 안의 글을 **그대로 복사 → 터미널에 붙여 넣기 → 엔터**만 하면 됩니다.

---

## 0. 준비물

| 필요한 것 | 비용 | 설명 |
|---|---|---|
| 컴퓨터 | - | 맥(애플 실리콘)에서 확인했습니다. 윈도우·리눅스는 아직 직접 확인하지 못했습니다 |
| Claude 계정 | 유료 | Claude Code 를 쓰려면 Pro 이상 요금제나 API 결제가 필요합니다 |
| 인터넷 | - | 자료 찾기와 무료 목소리(edge-tts)에 필요합니다 |
| 이 스킬 | **무료** | 오픈소스(MIT). 목소리·효과음·렌더도 무료입니다 |

---

## 1. 터미널 열기

- **맥**: `⌘ + 스페이스` → `터미널` 입력 → 엔터
- **윈도우**: 시작 버튼 → `PowerShell` 입력 → 엔터

검은(또는 흰) 창이 뜨면 성공입니다. 앞으로 명령은 여기에 붙여 넣습니다.

---

## 2. 필요한 프로그램 설치 (처음 한 번만)

### 맥

① Homebrew(맥용 프로그램 설치 도구)가 없다면 먼저 설치합니다. 비밀번호를 물으면 맥 로그인 비밀번호를 입력하세요(입력해도 화면에 안 보이는 게 정상입니다).
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
설치가 끝나면 화면 마지막의 `Next steps` 에 나온 명령 두 줄을 그대로 복사해 실행하세요.

② 영상 도구(ffmpeg)와 파이썬 실행 도구(uv)를 설치합니다.
```bash
brew install ffmpeg uv
```

③ Chrome 브라우저가 없다면 [google.com/chrome](https://www.google.com/chrome/) 에서 설치합니다. 화면 움직임(모션)을 그리는 데 씁니다.

### 윈도우 (아직 직접 확인하지 못했습니다)
```powershell
winget install Gyan.FFmpeg
winget install astral-sh.uv
```
Chrome 도 설치해 주세요. 설치 후 PowerShell 을 껐다 켭니다.

## 3. Claude Code 설치

맥:
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
윈도우:
```powershell
irm https://claude.ai/install.ps1 | iex
```
설치가 끝나면 터미널을 껐다 켜고 `claude` 를 입력합니다. 처음에는 브라우저가 열리며 Claude 계정으로 로그인하라고 나옵니다.
> 설치 방법이 바뀌었을 수 있으니 막히면 [Claude Code 공식 안내](https://docs.claude.com/en/docs/claude-code/setup)를 확인하세요.

## 4. 스킬 설치 (쇼츠·카드뉴스·상세페이지·쇼핑 쇼츠·블로그 한 번에)

`claude` 를 실행한 화면(입력창)에 아래 두 줄을 **한 줄씩** 입력합니다.
```
/plugin marketplace add bunhine0452/open-studio
```
```
/plugin install open-studio@open-studio
```
설치가 끝나면 `/exit` 로 나왔다가 `claude` 로 다시 들어갑니다.

<details>
<summary>플러그인 명령이 안 될 때 (직접 복사하는 방법)</summary>

터미널에서:
```bash
git clone https://github.com/bunhine0452/open-studio
mkdir -p ~/.claude/skills
cp -r open-studio/skills/* ~/.claude/skills/
```
</details>

## 5. 설치 점검

Claude Code 입력창에 이렇게 말합니다.
```
쇼츠 스킬 설치 점검해 줘
```
Claude 가 점검 도구(doctor)를 돌려 ✅ / ❌ 를 보여 줍니다. ❌ 가 있으면 옆에 나온 설치 명령을 Claude 에게 "이거 설치해 줘"라고 하거나 직접 실행하세요.

## 6. 첫 쇼츠 만들기

① 영상을 모아 둘 폴더를 만들고 그 안에서 Claude Code 를 엽니다.
```bash
mkdir -p ~/my-shorts && cd ~/my-shorts && claude
```

② 주제를 한 줄로 말합니다. 아무 주제나 됩니다.
```
쇼츠 만들어 줘: 장마 오기 전에 집에서 챙길 것
```
```
쇼츠 만들어 줘: 아이폰 배터리 오래 쓰는 설정 3가지
```
```
쇼츠 만들어 줘: 핸드드립 커피가 쓴 이유
```

③ Claude 가 순서대로 진행하며 짧게 알려 줍니다.
자료 찾기 → 사실 확인 → 대본 → 읽는 소리 변환(3D → 쓰리디) → 테마 고르기 → 목소리 → 화면 → 검수.
권한을 물으면(명령 실행, 파일 쓰기) 내용을 보고 허락하면 됩니다.

④ 끝나면 영상이 여기에 생깁니다.
```
~/my-shorts/shorts/001-<영어 이름>/001-<영어 이름>.mp4
```
맥은 `open shorts` 로 폴더를 열 수 있습니다. 같은 폴더에 유튜브 제목·설명란(caption.txt)도 있습니다.

---

### 카드뉴스도 같은 방식이에요
```
카드뉴스 만들어 줘: 장마 오기 전에 집에서 챙길 것
```
```
이 링크를 카드뉴스로 만들어 줘: https://…
```
결과는 `~/my-shorts/cardnews/001-…/out/` 에 생겨요. `4x5` 폴더의 PNG 를 순서대로 인스타에 올리고, `caption.txt` 를 캡션에 붙여 넣으면 돼요. `reels.mp4` 는 같은 내용을 릴스로 올릴 때 써요.
처음 한 번 "내 브랜드는 ○○, 핸들은 @○○, 로고는 이 파일"이라고 말해 두면 다음부터 모든 카드에 들어가요.

### 다른 도구도 말 한마디로
```
상세페이지 만들어 줘. 상품은 ○○, 사진은 ~/Desktop/photos 폴더에 있어
```
```
이 상품으로 15초 쇼핑 쇼츠 만들어 줘 (쿠팡 파트너스 제휴야)
```
```
"전기요금 아끼는 법" 키워드로 블로그 글 써 줘
```
결과는 각각 `detailpage/`, `shorts/`, `blog/` 폴더에 생겨요. 블로그 글은 `out/post.html` 을 브라우저로 열어 전체 복사한 뒤 네이버·티스토리 편집기에 붙여 넣으면 서식이 그대로 들어가요.

## 7. 마음에 안 들면 말로 고치기

그대로 말하면 됩니다.

| 이렇게 말하면 | 바뀌는 것 |
|---|---|
| "테마를 네온으로 바꿔 줘" | 화면·전환·효과음 묶음 |
| "내 채널 이름은 ○○, 색은 진한 초록이랑 노랑으로" | 사용자 테마(채널 이름·색) |
| "목소리 후보 들려줘" | 한국어 목소리 3개 × 빠르기 3단계 샘플을 만들어 줍니다 |
| "남자 목소리로, 조금 더 빠르게" | 목소리·빠르기 |
| "첫 문장을 더 세게" / "30초로 줄여 줘" | 대본 |
| "자막에서 ○○를 강조해 줘" | 자막 강조어 |
| "효과음을 더 조용한 걸로" | 효과음 |
| "이 사진을 표지에 써 줘 (파일 경로)" | 표지 사진 |

테마 다섯 가지: **지면**(정리·팁) · **네온**(AI·보안) · **아케이드**(게임·퀴즈) · **차분**(요리·건강) · **뉴스**(속보·생활).

## 8. 유튜브에 올리기

직접 올리는 방법:
1. [studio.youtube.com](https://studio.youtube.com) → 오른쪽 위 **만들기** → **동영상 업로드**
2. mp4 파일을 끌어다 놓기 (세로 1080×1920 이라 자동으로 쇼츠가 됩니다)
3. 제목: `spec.json` 의 `title`, 설명: `caption.txt` 내용을 그대로 붙여 넣기
4. **아동용 아님** 선택 → 다음 → 공개 범위 선택 → 저장

Chrome 확장(Claude in Chrome)을 쓰고 있다면 "유튜브에 비공개로 올려 줘"라고 해도 됩니다. 올리기 전에 꼭 한 번 확인을 받습니다.

## 9. 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| `command not found: brew / uv / ffmpeg` | 2번 설치를 다시 하고 터미널을 껐다 켜기 |
| `Chrome 을 찾지 못했어요` | Chrome 설치, 또는 `uvx playwright install chromium`. 급하면 "간단 엔진으로 렌더해 줘"(--simple) |
| 목소리 만들기 실패 | 인터넷 연결 확인 후 다시. 무료 엔진(edge-tts)은 Microsoft 서비스라 가끔 막힐 수 있습니다 |
| 자막에 "에스에스에이치"처럼 한글 소리가 나옴 | "자막을 원래 표기로 고쳐 줘" |
| 영상이 60초를 넘음 | "50초 안으로 줄여 줘" |
| 글자가 화면 밖으로 나감 | "제목을 짧게 줄여 줘" |
| 처음부터 다시 하고 싶음 | 그 편 폴더를 지우고 다시 "쇼츠 만들어 줘" |
