# 쇼핑 쇼츠 만들기

이 스킬은 같은 플러그인의 쇼츠 엔진을 쓴다. `$SH = <이 폴더>/../shorts`, 누끼는 `<이 폴더>/../detailpage/scripts/cutout.py`.
먼저 `$SH/SKILL.md` 의 흐름(대본 → speakable → voice → render → 검수)과 `$SH/references/spec.md` 를 따른다. 여기서는 쇼핑에서 다른 점만 적는다.

## 받을 것 (한 번에 묻는다)
- 내 상품인가, 제휴(쿠팡 파트너스 등) 상품인가 — **제휴면 대가성 표기가 의무**다.
- 상품명, 핵심 장점 2~3개(근거 있는 숫자), 가격(정가·판매가·기준 날짜), 구매 경로(프로필 링크·고정 댓글)
- 사진: 내 상품이면 직접 찍은 사진. 제휴 상품이면 **판매처가 제휴 홍보용으로 허락한 이미지만**(쿠팡 파트너스 API·배너가 주는 이미지 등). 남의 상세페이지·리뷰 사진을 긁어 쓰지 않는다. 쿠팡 페이지를 자동으로 긁지 않는다(약관 위반).
- 길이: 15초(장면 3~4) 또는 30초(장면 5~6), 형식: 단일 상품 또는 TOP3

## 흐름
1. **훅 각도 세 개**를 써서 보여 주고 하나를 고르게 한다(사용자가 "알아서"면 가장 구체적인 것):
   불편 공감("점심이면 식는 커피?") · 숫자("12시간 따뜻한 물병") · 비교("텀블러 3만 원 vs 1만 원") · 반전("이거 물병 아니에요") · 사용 장면("출근길 가방에 넣고").
2. **누끼**: 흰 배경 정면 사진이 있으면 `uv run <detailpage>/scripts/cutout.py photos/x.jpg photos/x-cut.png`.
3. **spec.json** (쇼츠 형식 + 쇼핑 장면):
   - `photo`: 사진 한 장 꽉 차게 + 큰 글 (첫 장면 훅에 좋다) `{image, headline, at?}`
   - `product`: 누끼가 무대 위로 떠오르고 빛이 훑고 장점 칩이 하나씩 `{image(누끼 PNG), kicker, headline, chips[{text, at}], rank?}` (TOP3 면 `rank` 1·2·3)
   - `price`: 정가 줄 긋기 → 판매가 세어 올라감 → 할인율 도장 `{was, price(숫자), off, note, at_old, at}` — `note` 에 기준 날짜와 판매처("11월 4일 쿠팡 기준")를 꼭 쓴다. 가격은 바뀐다.
   - `end`: 구매 경로 `{photo, kicker, todo}` — 쇼츠 설명란 링크는 눌리지 않으니 "프로필 링크" 또는 "고정 댓글"로 안내
   - `"bgm": {"style": "pop"|"chill"|"tech"}` 코드로 합성한 배경음악(저작권 없음, 말할 때 자동으로 줄어듦). 상품 분위기로 고른다.
   - 제휴면 `"ad": true` → 화면에 '광고' 표시가 계속 붙는다.
4. **대본**: 공백 빼고 15초 70~90자, 30초 150~180자. 가격·숫자는 speakable 이 읽는 소리로 바꾼다(25,900원 → 이만오천구백 원).
5. **렌더**: `render.py <폴더>`(자막본) + `render.py <폴더> --no-captions`(무자막본, 플랫폼 자동 자막을 쓸 때).
6. **설명란·고정 댓글** (caption.txt / spec.pinned):
   - 제휴면 맨 앞에: `이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.` (판매처 문구를 그대로, '쿠팡'을 빼지 않는다). 고정 댓글에도 같은 문구 + 링크.
   - 가격 기준 날짜, 과장 표현 점검(`<detailpage>/scripts/detail.py` 의 문구 규칙과 같다: 최고·100%·의약품 오인 금지).
7. **올리기**: `$SH/references/upload.md`. 자동 댓글·DM 은 하지 않는다(스팸 정책).

## 자주 틀리는 것
- 할인가가 판매처 실제 가격과 다르면 표시광고법 위반이다. 올리기 직전에 다시 확인하고 `note` 날짜를 맞춘다.
- 누끼 PNG 는 위아래 여백 없이 잘린 것을 쓴다(cutout.py 가 자동으로 자른다).
- 15초에 장면 5개를 넣으면 읽을 틈이 없다. 장면당 3초 이상.
