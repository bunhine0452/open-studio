# 블로그 글 도우미

이 SKILL.md 가 있는 폴더를 `$BL` 라고 부른다. `uv run $BL/scripts/blog.py check|build|wp <폴더>`. 테마 색·글꼴은 같은 플러그인의 쇼츠 엔진을 쓴다.
먼저 읽는다: `references/post.md`(post.md 형식과 글쓰기 규칙). 문체 규칙은 `$BL/../shorts/references/writing.md`.

## 하지 않는 것
- 여러 계정 돌리기, IP 바꾸기, 사람 확인 없는 대량 자동 발행. 네이버·티스토리 운영 정책 위반이고 저품질 판정의 지름길이다.
- 남의 글을 문장째 옮기기. 표절 점검으로 잡는다.
- 써 보지 않은 제품의 체험 후기, 출처 없는 숫자.

## 흐름
1. **폴더**: 현재 작업 폴더의 `blog/<영어-slug>/`.
2. **검색 의도**: 키워드로 웹 검색해 상위 글들이 무엇을 답하는지 본다(방법·비교·가격·후기·문제 해결). 그 질문에 먼저 답하는 구조로 짠다. 상위 글에 없는 것(직접 해 본 결과, 최신 날짜의 공식 정보, 표)을 하나 이상 넣는다.
3. **자료**: 공식 문서·원문을 읽고 숫자를 확인한다. 참고한 원문은 `sources/NN.txt` 로 저장하고 post.md `sources` 에 `{title, url, file}` 로 적는다(표절 점검용).
4. **구조**: 제목(키워드 포함, 15~40자) 3안 → 하나 고르고 나머지는 `title_options`. 요약 50~160자. 첫 문단에 결론. 소제목(##) 3~6개. 표 하나 이상. 끝에 자주 묻는 질문 2~4개와 "오늘 해 볼 것".
5. **본문**: 공백 빼고 1,500~3,000자. 한 문단 2~4문장. 키워드는 300자에 한 번 정도. 그림은 `![대체 텍스트](images/x.png)` 로(대체 텍스트 필수).
6. **점검**: `blog.py check <폴더>` → 표절 의심·문체·광고 문구·키워드·길이·구조 경고를 고친다. 0개가 될 때까지(문체 1곳 경고는 직접 읽고 판단).
7. **만들기**: `blog.py build <폴더>` → `out/post.html`(브라우저로 열어 안내 상자 아래를 전체 복사 → 편집기에 붙여 넣기), `out/post.md`, `out/thumb-1200x630.png`(대표 이미지·공유용), `out/thumb-1000x1000.png`(네이버 정사각), `out/meta.txt`(제목·요약·태그).
8. **올리기**: 사람이 편집기에서 붙여 넣고 그림을 올린 뒤 발행한다. 워드프레스면 `blog.py wp <폴더>` 로 **초안**까지 만들 수 있다(환경 변수 WP_URL·WP_USER·WP_APP_PASSWORD). 공개 버튼은 사람이 누른다.
9. **보고**: 제목, 글자 수, 점검 결과, 결과 경로, 사람이 확인할 것(숫자·날짜·정책).

## 같은 내용을 다른 형식으로
같은 폴더의 글로 카드뉴스(`$BL/../cardnews`)·쇼츠(`$BL/../shorts`)를 이어서 만들 수 있다. 사용자가 원하면 글의 소제목을 장으로, 결론을 표지로 옮긴다.
