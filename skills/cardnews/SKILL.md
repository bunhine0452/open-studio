# 카드뉴스 만들기

이 SKILL.md 가 있는 폴더를 `$CARD` 라고 부른다. 렌더는 `uv run $CARD/scripts/cards.py <폴더>`. 글꼴·테마 색·효과음은 같은 플러그인의 쇼츠 엔진(`$CARD/../shorts`)을 같이 쓴다.
처음이면 `uv run $CARD/../shorts/scripts/doctor.py` 로 ffmpeg·uv·Chrome 을 점검한다.

먼저 읽는다: `references/layouts.md`(장 종류와 cards.json), 문체 규칙은 `$CARD/../shorts/references/writing.md` 의 '문체 점검'.

## 사용자에게 묻는 곳

1. **개요 확인(한 번)**: 장 수와 장마다 한 줄 메시지를 보여 주고 고칠 곳을 묻는다. 사용자가 "알아서"라고 했으면 묻지 않는다.
2. **브랜드**: 처음 쓰는 사용자면 채널 이름·핸들(@)·로고 파일·좋아하는 색이 있는지 한 번 묻고 `brand.json` 으로 저장해 다음부터 재사용한다. 없으면 테마 기본값.
업로드(인스타 게시)는 하지 않는다. 결과 폴더와 캡션을 건넨다.

## 흐름

0. **폴더**: 사용자가 말하지 않으면 현재 작업 폴더의 `cardnews/NNN-<영어-slug>/`.
1. **재료**: 주제면 웹 검색으로 최근 자료를 찾고 공식 출처로 숫자를 확인한다. 링크면 그 글을 읽는다. 사용자가 붙여 넣은 글이면 그 글만 쓴다(새 사실을 지어내지 않는다). 출처는 장의 `source` 와 캡션에 남긴다.
2. **개요**: 8~10장. 표지(왜 읽어야 하는지) → 문제 → 핵심 2~5장 → 디테일·비교·숫자 → 정리 → 할 일(cta). **한 장에 메시지 하나.** 할 말이 둘이면 장을 늘린다.
3. **문장**: 제목은 두 줄 안, 줄당 12자 안팎, 강조어 `[대괄호]` 한두 개. 본문은 두세 문장. 해요체. 줄을 끊고 싶은 곳은 `\n`. 숫자·날짜는 출처가 있는 것만.
4. **테마**: 쇼츠와 같은 다섯 가지(paper·neon·arcade·calm·news)나 사용자 테마(`{"base", "colors", "fonts"}`). 주제 분위기로 고르고 이유를 한 줄로 말한다. 폰트는 2종, 색은 브랜드 색 + 보조 색 하나를 넘기지 않는다.
5. **사진**: 사용자가 준 사진(표지 `image`, `image_mode: "bg"|"top"`)을 쓴다. 없으면 글자만으로 만든다(대부분 그게 더 잘 읽힌다). 남의 사진을 웹에서 가져다 쓰지 않는다.
6. **렌더**: `cards.py <폴더> --preview` → `out/contact.jpg`(휴대폰 크기로 줄인 전체)를 직접 본다. 출력 끝의 '확인 필요'(글이 넘쳐 줄인 장, 마지막 줄에 글자 하나 남은 장)를 고친다.
   다 되면 `cards.py <폴더> --size 4:5,1:1,9:16 --reels` → 크기별 PNG, PDF, `reels.mp4`, `caption.txt`.
7. **캡션**: cards.json 의 `caption`(첫 줄 훅 + 핵심 2~3줄 + 출처), `hashtags` 5~10개, 장마다 `alt`(시각장애인용 대체 텍스트, 인스타 고급 설정에 붙여 넣기).
8. **보고**: 장 수, 테마와 이유, 결과 경로(PNG 폴더·PDF·릴스·캡션), 확인 필요 항목.

## 자주 틀리는 것

- 제목이 세 줄을 넘으면 표지 힘이 빠진다. `--preview` 에서 줄이 많으면 글을 줄인다(글자 크기를 줄이는 건 마지막 수단).
- 1:1 은 세로가 짧아 같은 글도 넘치기 쉽다. 1:1 이 필요하면 1:1 미리보기도 본다(`--size 1:1 --preview`).
- `compare` 는 왼쪽이 나쁜 쪽, 오른쪽이 좋은 쪽이다.
- `stat` 의 숫자는 출처가 있어야 한다. 없으면 `point` 로 바꾼다.
- 릴스는 장마다 3.2초(표지 4초). 장의 `seconds` 로 바꾼다.
